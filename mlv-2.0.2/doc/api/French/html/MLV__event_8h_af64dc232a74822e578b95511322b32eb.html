◆ MLV_Event

enum MLV_Event

Énumère les différents types d'évènement de la bibliothèque MLV.

Valeurs énumérées
MLV_NONE 

Aucun évènement

MLV_KEY 

Evnènement provenant du clavier 

MLV_INPUT_BOX 

Évènement provenant de la validation d'un texte dans une boîte de saisie.

MLV_MOUSE_BUTTON 

Évènement provenant d'un clique de souris.

MLV_MOUSE_MOTION 

Évènement provenant du déplacement de la souris.

Exemples
advanced/08_zone_click.c, medium/01_keyboard_events.c, medium/02_mouse_events.c, medium/03_input_box_events.c, medium/04_events.c, et medium/06_colors.c.
