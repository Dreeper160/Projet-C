enum MLV_Button_state

Énumère les différents états possibles d'un bouton.

Valeurs énumérées
MLV_PRESSED 

Le bouton est en position appuyée

MLV_RELEASED 

Le bouton est en position relachée

Exemples
medium/01_keyboard_events.c, medium/04_events.c, et medium/06_colors.c.
