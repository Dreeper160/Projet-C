Pour faire les git push

Intediction de push sur la branch main 

ordre de push 
pour ajouter votre fonctionalité(dire ce que vous avez ajouter en 1 message)
`git checkout -b fonctionnalite-recherche`


1. Voir les fichiers modifiés
`git status`

2. Indexer (préparer) tous les fichiers modifiés
`git add .`

3. Enregistrer les modifications avec un message clair


`git commit -m "Ajout de la barre de recherche textuelle"`


`git push origin fonctionnalite-recherche`
